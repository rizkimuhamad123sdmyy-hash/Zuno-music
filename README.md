## ✨ Fitur

| | |
|---|---|
| 🎧 **Pemutar musik** | Cover besar, background blur dari cover, seekbar bergelombang, mini player, dan kontrol dari notifikasi |
| 📚 **Playlist** | Bikin playlist pribadi atau **kolaboratif bareng teman** lewat kode undangan |
| 🌍 **Dari komunitas** | Temukan playlist buatan pengguna lain, putar, lalu simpan ke Library kamu |
| 🎤 **Lirik** | Layar lirik dengan animasi halus, plus **terjemahan** otomatis sesuai bahasa HP |
| 🔍 **Cari** | Cari judul atau artis, riwayat pencarian, dan artis yang lagi trending |
| ⏰ **Sleep timer** | Atur jam, menit, dan detik, lalu musik berhenti sendiri |
| ❤️ **Disukai & Koleksi** | Simpan lagu favorit dan kelola koleksimu |
| 🔐 **Login Google** | Masuk sekali tap, tanpa bikin akun baru |
| 🌐 **Multi bahasa** | Indonesia, English, dan Español, ikut bahasa default HP |
| 🐞 **Ajukan bug** | Lapor masalah langsung ke developer dari menu Pengaturan |

## 📲 Cara install

1. Buka halaman **[Releases](../../releases)** dan unduh file `.apk` terbaru.
2. Buka file APK di HP kamu.
3. Kalau diminta, aktifkan **"Install dari sumber tidak dikenal"** untuk browser atau file manager yang kamu pakai.
4. Tap **Install**, lalu buka **Zuno Music** dan masuk dengan akun Google.

> **Catatan:** Zuno Music membutuhkan koneksi internet untuk memutar lagu dan memuat komunitas.

## 🛠️ Teknologi

- **Aplikasi:** Android (Java)
- **Server:** Node.js
- **Database:** PostgreSQL
- **Login:** Google Sign-In

## 💖 Dukung developer

Suka sama Zuno Music? Kamu bisa dukung lewat menu **Pengaturan > Dukung developer** di dalam aplikasi (QRIS). Setiap dukunganmu bikin Zuno makin berkembang. Makasih banyak! 🙏
